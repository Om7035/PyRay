# Mobile Deployment (Android/iOS)

PyRay mobile targets will be supported via Kivy/buildozer in Phase 4.

## Status

- Guidance and templates will be added when API stabilizes.

## Approach Overview

- Package Python app with Kivy.
- Map touch input to PyRay input.
- Build APK/IPA via buildozer/Xcode.

## Current Recommendation

- Develop on desktop, then port UI and input to Kivy for mobile prototypes.
